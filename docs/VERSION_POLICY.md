# Canonical versions

The repository's published immutable tags v1.0.1 and v1.0.2 are historical release versions. Older CHANGELOG headings v2-v7 describe successive content milestones; they do not establish corresponding GitHub releases. Preserve those headings as history, and do not reinterpret or move old tags.

VERSION is the canonical version for new buyer archives, starting with 1.1.0 for this structural/packaging improvement. Releases must point to a specific clean commit. A branch candidate may be published as a prerelease while its PR remains unmerged. No release proves Studio execution or supports every agent.

Free archive includes only the intentionally MIT skill tree and MIT LICENSE. Pro documentation in docs/pro is public documentation, excluded from the Free archive. No Pro implementation or archive is present or reconstructed.
